# Goutham Reddy S Portfolio

React, Vite, TypeScript, and Tailwind portfolio for GitHub Pages.

## Local Development

```bash
npm install
npm run dev
```

The local site usually runs at `http://127.0.0.1:5173/portfolio/`. If that port is busy, Vite will print the next available URL.

## Build

```bash
npm run build
```

`dist/` is generated by Vite and is intentionally ignored on the source branch.

## Deploy

Manual deployment:

```bash
npm run deploy
```

GitHub Actions deployment:

1. Push to the `main` branch.
2. Go to the repository settings.
3. Open Pages.
4. Set the source to `Deploy from a branch`.
5. Select the `gh-pages` branch and `/(root)`.

The site will be available at `https://gouthamgovardhan.github.io/portfolio/`.

## Content Updates

- Update personal data in `src/data/portfolio.ts`.
- Replace the resume at `public/assets/resume.pdf` when you update the one-page PDF.
- Profile images live at `public/assets/profile.jpg` and `public/assets/profile-formal.jpg`.
- Project architecture previews live in `public/assets/projects/`.
- Add public GitHub or demo links in the `PROJECTS` array when repositories are ready to share.
- Update publications in the `PUBLICATIONS` array when you add or revise research work.
- If the repository name changes, update `base` in `vite.config.ts`.

## Repo Hygiene

- `node_modules/`, `dist/`, and Vite cache are ignored and should never be committed to `main`.
- GitHub Actions builds `dist/` during deploy and publishes it to the `gh-pages` branch.
